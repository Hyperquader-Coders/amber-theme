# Kat800 Built-in Colour Profiles

Four profiles are baked in at fixed indices. They are always present regardless of config and cannot be overridden by user-defined profiles with the same name.

| Index | Name | Category |
|-------|------|----------|
| 0 | Kat800 Dark | terminal |
| 1 | Katai | katai |
| 2 | Mint | terminal |
| 3 | Amber Phosphorus | terminal |

---

## 0 — Kat800 Dark

Signature profile. Gunmetal background, cold chrome foreground, glowing red cursor (the robot cat's eyes). Steel/Terminator ANSI palette: blood-red accents, HUD teals, circuit greens, copper sparks.

| Foreground | `#b8cce0` |
| Cursor | `#e01515` |

| Foreground | `#e8e4de` |
